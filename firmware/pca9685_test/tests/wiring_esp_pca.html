ESP32 DevKit V1 ↔ PCA9685 PWM Driver

TEST 03 — MINIMUM HARDWARE · NO SERVOS REQUIRED

Connection Reference

# ESP32 Pin → PCA9685 Pin Signal Notes
1 GPIO21 (SDA) ──► SDA I²C Data 3.3 V logic; 400 kHz Fast-mode
2 GPIO22 (SCL) ──► SCL I²C Clock 3.3 V logic; 400 kHz
3 3V3 ──► VCC Logic power Logic only — ≈ 25 mA max
4 GND ──► GND Common ground Shared star ground

✅ What you need

  • ESP32 DevKit V1 (or WROOM-32)
  • PCA9685 breakout board
  • 4× jumper wires
  • USB cable to PC

⚠ Not needed for this test

  • Servos (ch0–ch15 can be unplugged)
  • Servo power supply (V+ rail)
  • MPU-6050 IMU
  • Raspberry Pi / UART

🔵 I²C Pull-ups

  • PCA9685 breakout has on-board 10 kΩ pull-ups
  • Works at 400 kHz with ≤ 30 cm wire
  • If using bare IC: add 4.7 kΩ SDA/SCL → 3.3 V
  • ESP32 has weak internal pull-ups (≈ 45 kΩ)

🟣 PCA9685 Address

  • Default address: 0x40 (all A0–A5 pins = LOW)
  • Do not bridge any address solder pads
  • Test scans full 0x01–0x7E range
  • Will halt with error if 0x40 not found
